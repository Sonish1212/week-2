# Week 2: Predicting Happiness Score Using GDP, Health, and Generosity

Overview

This project focuses on building a regression model to predict the Happiness Score of countries based on three key features: GDP per capita, Health (life expectancy), and Generosity. The project is part of my journey to complete one data science project every week in 2025.

Problem Statement

Happiness is an important indicator of the well-being of a country’s population. This project aims to predict the Happiness Score for countries using economic and social indicators, helping us better understand the factors influencing happiness.

Goals

Explore the dataset and perform descriptive statistics.

Understand the relationships between GDP, Health, Generosity, and Happiness Score.

Build a regression model to predict the Happiness Score.

Evaluate the model’s performance using metrics and visualizations.

Dataset

The dataset contains various features for countries worldwide, including:

Happiness Score: A numeric score representing happiness levels.

Economy (GDP per Capita): A measure of a country’s economic output.

Health (Life Expectancy): The average life expectancy of a country’s population.

Generosity: The willingness of people to help others.

Dataset Structure:

Total rows: 156

Total columns: 8 (Subset used: Happiness Score, Economy, Health, Generosity)
